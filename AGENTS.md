[jwvdvuurst/ai-hub](https://github.com/jwvdvuurst/ai-hub).

1. Follow this repository's local instructions and current code first.
2. Consult the ai-hub [general rules](https://github.com/jwvdvuurst/ai-hub/blob/main/rules/general_rules.md) and [personal project context](https://github.com/jwvdvuurst/ai-hub/blob/main/rules/personal-projects.md).
3. Use the relevant [ai-hub skills](https://github.com/jwvdvuurst/ai-hub/tree/main/skills), especially the personal-project, Processing, emulator, and GitHub review guidance when applicable.
4. If repository-local guidance conflicts with ai-hub, the repository-local guidance wins.
